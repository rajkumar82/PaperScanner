# PaperScanner

A Flutter (Android) scan-to-PDF app. Tap **Start scan**, tap the shutter to photograph a page,
then crop (drag the corners) and rotate it. Tap **Next** to scan another page or **Stop** to
finish, then **Save** (to the Downloads folder) or **Share** (also saves a copy to Downloads first, so the PDF is never lost). Anything the camera sees can be scanned - no page
detection. UI follows the shared web-app theme (blue-to-violet gradient buttons, system light/dark).

## How it works

- **Capture** (`lib/screens/capture_screen.dart`): live preview + shutter; autofocuses first.
- **Edit** (`lib/screens/edit_screen.dart`): rotate in 90 degree steps and a draggable crop
  rectangle. Shows the photo instantly via Flutter's native decoder; the slow pure-Dart
  rotate/crop/resize/encode runs once (in `compute()`) when you tap Next/Stop/Apply.
- **Library** (`lib/screens/scans_screen.dart`, `lib/screens/scan_detail_screen.dart`): the
  **Scans** button lists recent scans (thumbnail, date, page count, delete). A scan shows its
  pages with **Save**, **Share**, **Edit** (walks through the pages from the first, re-adjusting
  crop/rotation; tap a page to start from it) and **Add page**. There is no "Done" - everything
  is saved as you go.
- **Storage** (`lib/models/scan.dart`, `lib/state/scan_store.dart`): each scan is a folder
  `<app documents>/scans/<id>/` holding the untouched originals (`orig_*.jpg`), the rendered pages
  (`page_*.jpg`) and `scan.json` (id, createdAt, per page: original, rendered, turns, crop). Edits
  always re-render from the original, so re-cropping is lossless. A scan folder is only created
  once its first page is saved. Scans stay until deleted (or the app's data is cleared).
- **PDF** (`lib/services/pdf_service.dart`): one A4 page per scan page. Saving goes through a small
  MediaStore channel in `MainActivity.kt` (Android 10+); Share saves to Downloads first, then opens
  the share sheet.
- **Theme** (`lib/theme.dart`): palette and button widgets matching fileshare/clipboard/summary.

## Launcher icon

A paper with a camera badge on the shared-theme gradient, generated by `tool/gen_icon.py` (needs Pillow):

    python tool/gen_icon.py              # writes assets/icon/{icon,background,foreground}.png
    dart run flutter_launcher_icons      # regenerates android/app/src/main/res mipmaps

## Releases

Distributed as an Android APK via GitHub Releases, not the Play Store. The summary page links to
`releases/latest/download/paperscanner.apk`, which always resolves to the newest release - so
every release's APK asset must keep that exact filename:

    flutter build apk --release
    cp build/app/outputs/flutter-apk/app-release.apk build/app/outputs/flutter-apk/paperscanner.apk
    gh release create vX.Y.Z build/app/outputs/flutter-apk/paperscanner.apk \
      -R rajkumar82/PaperScanner --title "PaperScanner vX.Y.Z" --notes "..."

Tag the release to match the version in `pubspec.yaml`.

## Run locally

    flutter pub get
    flutter run            # needs an Android device or emulator; camera won't work in a simulator without a real/virtual camera
    flutter build apk --debug   # builds build/app/outputs/flutter-apk/app-debug.apk without needing a connected device

Verified working end to end on this machine: `flutter build apk --debug` completes and
produces an installable APK.

## Notes / current limitations (v1)

- Android only.
- Page location (`lib/services/page_locator.dart`) was tuned against real captures but will
  likely need further adjustment for other lighting/background/pen combinations.
